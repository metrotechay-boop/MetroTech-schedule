# מטרו-טק · מפת הדרך תשפ״ז

דף אינטראקטיבי בעברית עבור סטודנטים במטרו-טק. הדף מציג מסלול רכבת אינטראקטיבי בין שנות הלימוד וקהילת STEP-UP, אירועים, קישורי Zoom, הוספה ליומן Google/Outlook, משוב, מחויבויות ומועדי מלגות.

## עדכון תוכן
כל התוכן נמצא בקובץ `data.js`:
- `stations` — תחנות המסלול.
- `events` — אירועים. לכל אירוע אפשר לעדכן תאריך, שעות, מיקום, Zoom וקישור משוב.
- `deadlines` — מחויבויות.
- `scholarships` — מועדי המלגות.

הקישורים ל-Google Calendar ול-Outlook נוצרים אוטומטית לפי פרטי האירוע.

## הפעלה
זהו אתר סטטי, ולכן אפשר לפתוח את `index.html` ישירות בדפדפן או לפרסם את המאגר דרך GitHub Pages.

> הקישורים הזמניים ל-Zoom ולמשוב בנתוני הדוגמה מיועדים להחלפה על ידי הצוות.
